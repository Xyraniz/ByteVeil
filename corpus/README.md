# Registro del corpus autorizado

Esta carpeta contiene únicamente metadatos. No se distribuyen muestras externas ni el repositorio completo de `Obfuscator-Samples`.

Las futuras entradas deben registrar nombre, URL, commit o versión, categoría/protector, formato detectado, si solo se inspeccionó o se ejecutó en un entorno autorizado, resultado, nivel de recuperación, información perdida y limitaciones. Luraph no forma parte de la fase inicial.

En ByteVeil 0.3.0 no se utilizaron muestras externas; las regresiones son sintéticas y locales.
